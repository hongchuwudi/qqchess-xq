下载 Python 3.11.9 安装包（64位），
安装时务必勾选 "Add Python to PATH"，
安装完成后点击「重新检测」。

安装方法：打开 CMD 或 PowerShell，执行：
pip install mitmproxy
安装完成后点击「重新检测」。
